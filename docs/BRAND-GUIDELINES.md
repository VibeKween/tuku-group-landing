**identity**

| field | value |
|---|---|
| legal name | Tuku Group, LLC |
| brand name | TUKU GROUP (all caps, always) |
| founded | 2025 |
| structure | independent and privately held |
| location | New York |

The brand name is never written as "Tuku group", "tuku group", or "TukuGroup". It is TUKU GROUP - two words, all caps, with a space.

```
//
```

**positioning**

- Primary descriptor - "Independent Creative House"
- Mission line - "Independent ideas. Thoughtful brands. Assembled with intention."
- Purpose line - "A creative house for ventures that hold meaning."
- Ethos - "Craft over noise. Fewer, better, slower."

The word "agency" is never used. TUKU GROUP is a creative house - the distinction is intentional. Agencies serve clients. A creative house builds what it believes in and works alongside brands that share its ethos.

```
//
```

**voice and tone**

Declarative. Direct statements without explanation. Professional without corporate jargon. Confidence without volume.

What the voice does -

- States facts. Does not sell.
- Uses intentional brevity. Every word earns its place.
- Opens with questions or claims. Never with filler.
- Says "start a conversation" instead of "get a quote."
- Uses line breaks for emphasis and rhythm.

What the voice avoids -

- Superlatives. Nothing is "revolutionary" or "cutting-edge."
- Exclamation marks. Period.
- Industry jargon or buzzwords.
- Promotional language of any kind.
- Emoji in professional contexts.

```
//
```

**color system**

Core palette -

```
black       #000000    primary text and backgrounds
white       #FFFFFF    background and inverted text
gold        #C19A4B    philosophy headers and accents
```

TUKU blue palette - used on studio and payment pages -

```
blue-light      #f0f9ff    light backgrounds
blue-medium     #e0f2fe    medium selections
blue-accent     #5691c8    links and buttons
blue-deep       #4a7ba7    hover states
```

Gold is reserved for philosophy headers - the `.philosophy-header` spans that call out key concepts. It is never used for buttons, links, or decorative elements.

```
//
```

**logo and favicon**

The logo is text-based. "TUKU GROUP" set in JetBrains Mono. No icon mark, no symbol, no graphic treatment. The typography is the identity.

The favicon is a simple cloud icon in TUKU blue (#5691c8). The same cloud appears as the social sharing card image.

The OG image (`images/tuku-group-og-compact.png`) is 1200x630px - the cloud positioned to hide its left tail for clean alignment in iMessage, Slack, and social previews. Light gradient background from #e8eef5 to #d8e4f0.

```
//
```

**content patterns**

Philosophy headers use gold `.philosophy-header` spans for key concepts within body text. These are the only decorative text treatment in the system.

Sections follow a manifesto structure - one concept per `<section class="block">`. Each section is self-contained. The reader can stop after any section and still have received a complete thought.

Contact is always framed as conversation, not transaction. The branded email subject line maintains consistency across touchpoints.

```
//
```

**what not to do**

- Do not use the TUKU GROUP name in lowercase or mixed case
- Do not describe the company as an "agency" or "firm"
- Do not use gold for anything other than philosophy headers
- Do not add emoji to any brand touchpoint
- Do not use promotional language in any context
- Do not pair the brand with stock photography
- Do not break the monospace typography system
